# 43 - A Prediction Put to a Legislature

The mechanism says an asset-tested system needs a withdrawal rule whose payment reads the balance. The country whose means test this study calibrates to legislates one -- a minimum annual payment set as a percentage of the account balance, rising with age. The rates are statute. Running them is the closest thing to an out-of-sample test this project can perform.

## What the test finds

**The prediction holds, and nothing in it was tuned.** Under the means test the all-equity portfolio leads by +12.22% when the retiree draws the legislated minimum, and trails by 11.38% when it draws the fixed real amount the literature assumes -- a swing of 23.6 points between a rule a legislature wrote and a rule a literature adopted. The mechanism said an asset-tested system needs the first shape. It has one.

**What this is not.** It is an institutional anchor, not a behavioural one. A design fact is not a holdings fact: this says the rule shape a means-testing country legislates is the shape the model says such a country needs, and says nothing about how its retirees invest. The behavioural implication is stated here in falsifiable form rather than left implied. Retirement-phase portfolios in a system that both means-tests the public pension and mandates a percentage-of-balance drawdown should sit at the high-equity end relative to a target-date glide path at the same age. It would be settled by Fund-level retirement-phase asset allocation by member age, against target-date glide paths at matched ages. Neither is carried here. -- and could not be settled here, because the egress policy this project runs under denies every bulk statistical host, which `docs/14` and `src.observed` document at length. A reader with that data can refute this paper cheaply, which is the point of writing the claim down.

## How it is run

The legislated schedule is implemented as a spending rule in
`src.spending` -- a percentage of the balance whose rate is read off
the member's age -- and run through the same simulator, on the same
panel, against the same two portfolios as every other rule in this
project. Nothing about the household, the returns or the pension
changes between the rows: only which rule the retiree spends by.

The source is Superannuation Industry (Supervision) Regulations 1994, Schedule 7. The rates are quoted in the table above
so a reader can check the simulation against the law rather than
against this document.

Multiples of the minimum are run as well, because the statute sets a
floor rather than a rate and a retiree may draw more than it
requires. 25,000 lifetimes per cell, gamma = 5,
survival-weighted, with the fixed real rule (fixed_real_rule) as the
comparator the prediction says should fail.
